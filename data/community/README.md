# Community dataset (bundled)

Shared **sanitized** combat/fishing move logs:

- `combat.jsonl` — one combat record per line (schema `v: 1`, `kind: "combat"`)
- `fishing.jsonl` — one fishing step per line (`kind: "fishing"`, `board: 3|4`)

0.1.1 bundles 2,169 privacy-safe combat exchanges. Nothing is uploaded automatically. Users load this pack via **Load bundled dataset**, or import a community file they saved themselves.

Only files created by **Export community** are intended for sharing. Do not put `actionToken`, JWT, cookies, authorization headers, seed phrases, private keys, or wallet addresses in these files.
