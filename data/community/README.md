# Community dataset (bundled)

Place shared **sanitized** combat/fishing move logs here later:

- `combat.jsonl` — one combat record per line (schema `v: 1`, `kind: "combat"`)
- `fishing.jsonl` — one fishing step per line (`kind: "fishing"`, `board: 3|4`)

Nothing is uploaded from the extension. Users load this pack via **Load bundled dataset**, or import a file they saved themselves.

Do not put `actionToken`, JWT, cookies, or wallet addresses in these files.
